🧪 Labs Práticos

Exercícios hands-on para desenvolver habilidades reais — do básico ao enterprise.

🔰 Labs Iniciante

Iniciante

Lab 01 — Stack LGTM com Docker Compose

Configure Loki, Grafana, Tempo e Mimir (Prometheus) localmente usando Docker Compose. Explore os datasources no Grafana e entenda a arquitetura LGTM na prática.

Objetivo: Subir uma stack completa localmente em menos de 10 minutos.

Docker Compose Grafana Prometheus Loki Tempo
Iniciante

Lab 02 — Primeiros Logs Estruturados

Modifique uma aplicação de exemplo para emitir logs em JSON com campos padronizados: timestamp, level, service, trace_id, message. Visualize no Grafana com LogQL.

Objetivo: Entender por que logs estruturados são fundamentais.

JSON Logging Loki LogQL Grafana
Iniciante

Lab 03 — Expose /metrics com Prometheus

Adicione um endpoint /metrics em uma aplicação Python (Flask) ou Node.js com contadores e histogramas. Configure o Prometheus para fazer scraping e crie seu primeiro dashboard.

Objetivo: Expor e visualizar métricas de aplicação.

Prometheus Client Prometheus Grafana PromQL
Iniciante

Lab 04 — Dashboard dos Golden Signals

Crie um dashboard com os 4 Golden Signals (Latency, Traffic, Errors, Saturation) para uma aplicação de exemplo. Use variáveis para filtragem por serviço e ambiente.

Objetivo: Dominar dashboards baseados em Golden Signals.

Grafana Prometheus PromQL Dashboard Variables

⚙️ Labs Intermediários

Intermediário

Lab 05 — Instrumentação com OpenTelemetry

Instrumente uma aplicação multi-serviço (API + worker + banco) com OpenTelemetry SDK. Configure context propagation entre serviços. Visualize traces correlacionados com logs no Grafana.

Objetivo: Implementar distributed tracing de ponta a ponta.

OpenTelemetry SDK OTel Collector Grafana Tempo Loki Trace-to-Logs
Intermediário

Lab 06 — OTel Collector Pipeline

Configure um OTel Collector com múltiplos receivers (OTLP, Prometheus), processors (batch, filter, attributes) e exporters (Loki, Tempo, Prometheus). Filtre traces de health checks.

Objetivo: Dominar pipelines de telemetria.

OTel Collector OTLP Processors Pipelines
Intermediário

Lab 07 — Alertas Baseados em SLO

Defina um SLO de disponibilidade (99.9%) para um serviço HTTP. Configure alertas multi-window burn rate com Alertmanager. Envie alertas para Slack. Teste o erro budget.

Objetivo: Implementar SLO-based alerting profissional.

Prometheus Alertmanager SLO Sloth Slack
Intermediário

Lab 08 — Kubernetes Observability com kube-prometheus

Instale o kube-prometheus-stack em um cluster K8s (kind/minikube). Explore dashboards de cluster, nodes e pods. Configure ServiceMonitor para sua própria aplicação.

Objetivo: Monitorar Kubernetes com a stack padrão.

kube-prometheus-stack Helm ServiceMonitor Kubernetes
Intermediário

Lab 09 — Debugging de Latência com Traces

Uma aplicação de e-commerce tem lentidão esporádica. Use distributed traces para identificar qual microserviço é o gargalo. Analise spans de banco de dados e chamadas externas.

Objetivo: Usar traces para identificar gargalos reais.

Grafana Tempo TraceQL OpenTelemetry Span Analysis

🚀 Labs Avançados

Avançado

Lab 10 — Thanos para Multi-cluster

Configure Thanos com dois Prometheus em clusters diferentes. Use Thanos Query para consultas federadas. Configure upload para S3. Implemente downsampling e compaction.

Objetivo: Federação de métricas entre múltiplos clusters.

Thanos Prometheus S3 / MinIO Multi-cluster
Avançado

Lab 11 — eBPF com Cilium e Hubble

Instale Cilium como CNI em um cluster Kubernetes. Ative Hubble para observabilidade de rede L3/L4/L7. Observe fluxos de rede e DNS. Implemente Network Policies baseadas em identidade.

Objetivo: Observabilidade de rede com eBPF.

Cilium Hubble eBPF Network Policies
Avançado

Lab 12 — Continuous Profiling com Pyroscope

Adicione profiling contínuo de CPU e memória em uma aplicação Go e Python usando Pyroscope. Identifique funções que consomem mais recursos. Correlacione profiles com traces no Grafana.

Objetivo: Identificar hotspots de performance com profiling contínuo.

Pyroscope Grafana Flamegraphs Go / Python
Avançado

Lab 13 — Chaos Engineering com Grafana

Use Chaos Mesh para injetar falhas em um cluster Kubernetes enquanto observa o impacto nos dashboards, traces e alertas. Valide se os SLOs e alertas respondem corretamente.

Objetivo: Validar observabilidade sob falhas reais.

Chaos Mesh Grafana SLO Alerting Kubernetes

⭐ Labs Expert

Expert

Lab 14 — Plataforma Multi-tenant de Observabilidade

Construa uma plataforma completa com Mimir, Loki e Tempo em modo multi-tenant. Configure RBAC, limites de cardinalidade por tenant, dashboards de custo e billing. Integre com OTel Operator.

Objetivo: Construir uma plataforma enterprise de observabilidade.

Mimir Loki Multi-tenant Tempo OTel Operator RBAC
Expert

Lab 15 — Observabilidade para LLMs e IA

Instrumente uma aplicação de chatbot com LLM (OpenAI/Ollama) usando OpenLLMetry. Rastreie tokens, latência de inferência, erros e custo por request. Crie dashboards de AI observability.

Objetivo: Aplicar observabilidade moderna a sistemas de IA.

OpenLLMetry OpenTelemetry Grafana LLM Metrics AI Tracing
Expert

Lab 16 — FinOps: Reduzindo Custo de Métricas em 60%

Analise uma stack com alta cardinalidade usando a API do Mimir. Identifique métricas desnecessárias. Implemente relabeling para dropar, agregar e reduzir volume. Valide a redução de custo.

Objetivo: Reduzir custo de observabilidade sem perder visibilidade.

Mimir Cardinality API Prometheus Relabeling Adaptive Metrics FinOps
