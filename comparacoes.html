🗂️ Loki vs ELK Stack

CritérioGrafana LokiELK Stack
IndexaçãoApenas labels (baixo custo)Full-text index (alto custo)
Custo de Storage✓ Muito baixo (chunks comprimidos)✗ Alto (índices Elasticsearch)
Velocidade de Busca~ Média (busca no conteúdo é mais lenta)✓ Rápida para full-text
Linguagem de QueryLogQLKQL / Lucene
Integração Grafana✓ Nativa (mesma stack)~ Via plugin
Complexidade Operacional✓ Baixa✗ Alta (JVM, cluster ES)
Multi-tenancy✓ Nativo~ Requer configuração
Alertas de Log✓ Via Ruler✓ Via Watcher/Kibana
Analytics Avançado~ Limitado✓ Kibana Lens, TSVB
Caso de Uso IdealCloud-native, Kubernetes, custo baixoFull-text search, analytics, SIEM
